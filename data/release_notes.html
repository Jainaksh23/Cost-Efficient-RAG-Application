Vaultly Release Notes

Version 2.4.1 - March 12, 2025

  • Bug Fix: Fixed a bug causing duplicate file uploads when the network connection dropped mid-transfer. Files uploaded over an interrupted connection are now safely deduplicated on the server side.
  • Performance: Improved search indexing speed by 40% through parallel shard processing. Large workspaces with over 10,000 documents will see the most benefit.
  • Security: Updated the TLS certificate rotation schedule from annual to quarterly to comply with emerging browser policies.

Version 2.4.0 - February 3, 2025

  • New Feature: Introduced AI-powered document summarization. Vaultly can now generate a concise summary of any uploaded document. Access this feature from the document detail page by clicking "Summarize."
  • New Feature: Folder-level permissions. Admins can now restrict access to individual folders, independent of workspace-level roles.
  • Improvement: Reduced document upload time for files larger than 20 MB by switching to chunked multipart uploads.

Version 2.3.5 - December 18, 2024

  • New Feature: Added support for SAML 2.0 SSO. Enterprise customers can now configure Vaultly as a Service Provider in their identity provider (Okta, Azure AD, OneLogin). Configuration is available under Settings > Security > SSO.
  • Bug Fix: Fixed an issue where shared document links did not respect the expiration date set at creation time.

Version 2.3.0 - October 7, 2024

  • New Feature: Launched the Vaultly mobile app for iOS and Android. The app supports document browsing, photo uploads, commenting, and offline viewing of recently accessed documents.
  • New Feature: Added CSV export for search results and document metadata.
  • Improvement: Dashboard loading time reduced by 60% through aggressive server-side caching.

Version 2.2.0 - July 14, 2024

  • New Feature: Version history for all documents. Every save creates a new version. Starter plans retain 30 days of history; Professional and Enterprise retain unlimited history.
  • New Feature: Bulk document download as a ZIP archive.
